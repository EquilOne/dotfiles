# Edge Cases

| Situation | Action |
|-----------|--------|
| Plan has no clear steps (loose prose) | Confirm extracted step list with user before continuing |
| User rates everything 4 or 5 | Ask one applied calibration question before accepting |
| Concepts span rating 1 AND rating 5 in same module | Default to "Full" fade stage; advanced concept is vehicle for teaching beginner one |
| Plan has >20 steps | Warn: "N modules will be generated. Want me to group into phases instead?" |
| Same concept appears in multiple steps | Reference back in later modules; don't re-introduce. Apply depth from original rating |
| Plan references proprietary/internal tools | Flag as "may not be available." Provide open-source alternatives. Never assume access |
| Plan is purely theoretical (no code) | Add "Thought Exercise" section per module — a question the learner answers in writing |
| No source material (Path B) | Skip action density extraction. Start at quest definition. Ask: "What's the smallest thing you could ship in 7 days?" |
| Ambiguous quest (Path B) | Push back until measurable. Offer 2–3 concrete options. Don't proceed without measurable quest |
| Pure theory content with no action (Path B) | Action density will be very low. Ask: "(a) find different source, (b) extract conceptual framework and design reps around applying it, or (c) abandon skill?" |
| Rep stuck at 3+ failed attempts (Path B) | Cut the rep in half. Ship the smaller version today. Rep is wrong, not the learner |
