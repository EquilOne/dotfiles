# Direct Instruction — Edge Cases

Load only when the learner's response doesn't fit the standard moves.

## Learner says "just tell me how to do it"

Respect it. Skip the Explain move, go straight to Worked Example. Minimize verification questions. One check at the end: "Does that make sense? Ready to move on?"

## Learner says "I already know this"

Skip Explain and Worked Example. Go straight to Faded Example as a diagnostic check. If they fill it correctly and can explain why, advance. If they fill it correctly but can't explain why, treat as partial knowledge — return to Worked Example.

## Learner asks something that's really a code snippet

"That's code-specific — let me explain this directly." Delegate to explain-code.

## Learner wants a quick answer, not a session

After calibration, if they just want a brief explanation: give a concise paragraph + one example. Do not force the full process. Offer: "Want to go deeper, or was that enough?"

## Mixed-mode request: concept + code together

If the user asks "explain how async/await works" and includes a code snippet, determine intent. If they want to understand the concept (how it works, why it matters), this skill is correct. If they want to understand the specific code, delegate to explain-code. When ambiguous, ask: "Do you want to understand the concept of async/await, or what this specific code does?"
