# Calibration → Behavior Mapping

Reference for teach-from-lesson Phase 3 Delivery. Maps 9 familiarity + pacing
combinations to presentation mode, check frequency, and module pace.

| Familiarity   | Pacing   | Presentation                               | Checks                 | Module Pace                   |
| ------------- | -------- | ------------------------------------------ | ---------------------- | ----------------------------- |
| New           | Thorough | Full walkthrough, annotated                | After every chunk      | Slow (1 chunk -> check -> next) |
| New           | Normal   | Full walkthrough, fewer annotations        | After every 2 chunks   | Medium                        |
| New           | Fast     | Summarize, focus on key insight            | After key insight only | Medium-fast                   |
| Some exposure | Thorough | Recap + depth on nuances                   | After every chunk      | Medium                        |
| Some exposure | Normal   | Brief recap, explain what's new            | After each section     | Normal                        |
| Some exposure | Fast     | One-paragraph recap, jump to exercises     | After exercise         | Fast                          |
| Comfortable   | Thorough | Surface non-obvious pitfalls only          | After each pitfall     | Fast                          |
| Comfortable   | Normal   | Jump to exercises, explain only when stuck | On wrong answer only   | Fast                          |
| Comfortable   | Fast     | State objective, let learner drive         | On request only        | Express                       |
